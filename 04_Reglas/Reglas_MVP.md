# Reglas MVP

## CON-001 — Plazo de pago

**Condición:** comparar el plazo propuesto con el mínimo aceptable configurado (`PAG-001`).

- Si `Plazo_propuesto < PAG-001`: incumplimiento del mínimo → **R2 / NEGOCIAR**.
- `PAG-002` representa el **plazo objetivo de negociación** y se utiliza como referencia adicional para valorar el margen de negociación.

> La terminología «mínimo objetivo» queda sustituida para evitar ambigüedad entre mínimo aceptable y objetivo de negociación.
