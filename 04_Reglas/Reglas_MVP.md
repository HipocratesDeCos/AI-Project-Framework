# Reglas MVP

## CON-001 — Plazo de pago

**Condición:** comparar el plazo propuesto con el mínimo aceptable configurado (`PAG-001`) y utilizar el plazo objetivo (`PAG-002`) como referencia de negociación.

- Si `Plazo_propuesto < PAG-001`: incumplimiento del mínimo aceptable → **R2 / NEGOCIAR**.
- Si `Plazo_propuesto >= PAG-001`: no existe incumplimiento del mínimo; `PAG-002` se utiliza como referencia adicional para valorar el margen de negociación.

> La terminología «mínimo objetivo» queda sustituida para evitar ambigüedad entre mínimo aceptable y objetivo de negociación.
