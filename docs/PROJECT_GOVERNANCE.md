# PROJECT GOVERNANCE
## AI Project Framework

Versión: 1.0
Estado: Activo

---

# 1. Propósito

Definir las normas de funcionamiento del proyecto para garantizar su estabilidad, trazabilidad y escalabilidad.

---

# 2. Principios

1. Una única fuente oficial de conocimiento.
2. Toda decisión importante debe documentarse.
3. Ningún cambio se realiza sin registrar su motivo.
4. Cada sesión finaliza actualizando la documentación.
5. Todo el proyecto debe poder entenderse sin leer el historial del chat.

---

# 3. Jerarquía documental

La documentación tendrá la siguiente prioridad:

1. BASELINE
2. PROJECT CHARTER
3. ADR (Architecture Decision Records)
4. DOCUMENTACIÓN FUNCIONAL
5. SESSION LOG

Si existe un conflicto, prevalece el documento de mayor jerarquía.

---

# 4. Flujo de trabajo

Idea

↓

Análisis

↓

Propuesta

↓

Aprobación

↓

Documentación

↓

Baseline

---

# 5. Control de versiones

Versionado:

v0.x → Diseño

v1.x → Desarrollo

v2.x → Producción

---

# 6. Fuente oficial

La documentación almacenada en GitHub constituye la única fuente oficial del proyecto.

Las conversaciones sirven para trabajar, pero no sustituyen la documentación.

---

# 7. Objetivo

Crear un sistema de conocimiento que pueda mantenerse durante años sin perder coherencia.
